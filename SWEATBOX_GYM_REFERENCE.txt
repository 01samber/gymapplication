SECTION 9: ADMIN DASHBOARD SETUP
--------------------------------------------------------------------------------

1. Create .env.local:
   Copy from admin\.env.local.example and fill in Supabase credentials.

2. Run migrations:
   npx supabase db push
   (from project root)

3. Create admin user:
   • Enable Email auth: Supabase → Authentication → Providers → Email
   • Sign up via app or Supabase Auth
   • Run in Supabase SQL Editor:
     INSERT INTO profiles (id, email, full_name, role)
     VALUES ('YOUR-USER-UUID-FROM-AUTH', 'admin@yourgym.com', 'Admin', 'admin')
     ON CONFLICT (id) DO UPDATE SET role = 'admin';

4. Verify:
   Open http://localhost:3000 and log in with admin email/password.

NOTE: "db push --linked" is NOT a valid command. Use: npx supabase db push
